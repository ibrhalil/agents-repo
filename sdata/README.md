# sdata/ — Yapılandırılmış Uygulama Verisi

Agent'ın programatik okuyup yazdığı küçük JSON/YAML dosyaları: habit takibi,
görev listesi, sayaçlar vb. Bilgi tabanının (wiki) parçası değildir; şema her
dosyanın kendi içinde belgelenir. Yazma: hızlı şerit (doğrudan main).
Örnek: `habits.json`, `tasks.json`
