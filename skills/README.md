# skills/

Agent'lerin prosedürel belleği: bir işin hangi yöntemle yapıldığı. Tool = ne
yapabiliyor; skill = nasıl yapılıyor (ayrım AGENTS › Kod). Mevcut: `llm-wiki`
(bu reponun uyguladığı kalıcı wiki deseninin alan-bağımsız tanımı; repo varyantı
için SKILL.md › "Bu repoda"). Planlanan skill'ler (Faz 2-3): `ingest` (inbox +
oturum işleme), `consolidate` (gece cron), `tend` (bahçe bakımı), `lint`
(haftalık).
